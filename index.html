Git là gì?

Distributed version control system: ghi lại lịch sử thay đổi của từng file trong dự án.

  • Linus Torvalds viết năm 2005 để quản lý source code của Linux kernel
  • Mỗi lần lưu là một snapshot toàn bộ dự án
  • Mỗi máy giữ đủ lịch sử, không cần mạng vẫn làm việc được

merge hay rebase?

merge

Tạo thêm merge commit M. Giữ nguyên lịch sử thật, an toàn, dễ hiểu. Mặc định nên dùng cái này.

rebase

Chép C, D thành C′, D′ đặt lên sau E. Lịch sử thẳng, gọn, nhưng viết lại commit: đừng rebase branch người khác đang dùng.

Từ fork tới pull request

cac-buoc.sh
# 1. fork về tài khoản của bạn và clone xuống máy
$ gh repo fork ftulabs/ftulabs.github.io --clone && cd ftulabs.github.io
# 2. tạo branch riêng
$ git switch -c feature/k65-nguyenvana
# 3. tạo file của bạn từ mẫu, rồi sửa trong IDE
$ cp k65/members/_template.json k65/members/nguyenvana.json
# 4. commit đúng 1 lần
$ git add k65/members && git commit -m "feature: Add K65 member Nguyen Van A"
# 5. đẩy lên và mở PR
$ git push -u origin HEAD && gh pr create --fill
